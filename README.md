# مُدقِّق الطابعي

برنامج ويندوز يدقق الملازم الدراسية بدون إنترنت:
- **تدقيق إملائي وترقيم وقواعد بسيطة** للنص الإنكليزي، عن طريق LanguageTool المحلي.
- **مطابقة النصوص المنقولة ويّا الكتاب الرسمي:** يقرأ الكتب المصورة سكنر بـTesseract OCR.
- **تقرير PDF:** بيه الجملة كاملة، والخطأ بالأحمر، والتصحيح بالأخضر، وشعار الطابعي بالخلفية.

## التنصيب
نزّل المستودع ZIP، وفك الضغط، وشغّل `INSTALL.bat`. يحتاج إنترنت مرة وحدة بس.

## التحديث
تحدّث البرنامج من زر **«تحديث البرنامج»**. الزر يقرأ ملف `version.json` من هذا المستودع.
لما تنشر نسخة جديدة: غيّر `VERSION` بملف `mudaqqiq.py`، وغيّر `version` بملف `version.json`، وارفع الملفين.
