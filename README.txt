مدقق الطابعي — تدقيق الملازم بدون نت
=====================================

التنصيب (مرة وحدة، يحتاج نت):
1) فك ضغط المجلد بأي مكان.
2) (اختياري) حط لوگو الطابعي باسم logo.png داخل نفس المجلد قبل التنصيب.
3) دبل كلك على «INSTALL.bat» وانتظر لحد ما تطلع رسالة «تم التنصيب».
   - التحميل الكلي تقريباً 700 MB (أكبر شي LanguageTool).
   - إذا طلع طلب صلاحية (UAC) لـ Tesseract وافق عليه.
   - سجل التنصيب ينحفظ في: %LOCALAPPDATA%\Mudaqqiq\install-log.txt

الاستخدام (بدون نت):
1) افتح «مدقق الطابعي» من سطح المكتب.
2) اختار الملزمة PDF، وأضف الكتب الرسمية (كتاب الطالب + كتاب النشاط).
3) اختار اللوگو ومكان حفظ التقرير، ودوس «ابدأ التدقيق».
4) أول مرة لكل كتاب ياخذ وقت (OCR للكتاب السكنر، 5-10 دقائق) وبعدها ينحفظ وتصير أسرع.
5) يطلع تقرير PDF + HTML + JSON بنفس المجلد اللي اخترته.

شنو يلگى:
- أخطاء الـspelling الإنكليزي، الحروف الكبيرة، الترقيم، قواعد بسيطة (LanguageTool).
- الكلمات المنقولة غلط من الكتاب (مثل Line بدل Lina)، الكلمات الملتصقة (isEnglish)، الأرقام المختلفة.
- إملاء عربي أولي (معلّم «يحتاج تأكيد» لأن الـPDF أحياناً يشوّه العربي).

شنو ما يلگى:
- التدقيق العلمي: الأجوبة الغلط، أرقام الصفحات والتمارين، الترجمة الغلط، شرح القواعد.
  هذا يحتاج Claude.

الكلمات اللي ما تعتبر أخطاء (أسماء شخصيات وأماكن) تكدر تضيفها في:
%LOCALAPPDATA%\Mudaqqiq\config.json  ←  "extra_words": ["Yousif", "Karim", ...]
